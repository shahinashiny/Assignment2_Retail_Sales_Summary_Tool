# Data files

- `superstore.csv` is the input dataset used by the Retail Sales Summary Tool. The loader reads it as a comma-separated text file.
- The project currently also contains `Health_Risk_Tiers.csv`, which is not used by the retail-sales code. Review its purpose and redistribution rights; remove it if it was included by mistake before making the repository public.

Use only data you have permission to redistribute. Do not add customer-sensitive, confidential, or licensed data to a public repository.
